# POSCloud Lite — версия для старых Windows (7+)

Лёгкий клиент синхронизации **без WebView2**: интерфейс на нативном Win32 API,
движок — общий модуль `poscloud-engine` (тот же код, что в обычном клиенте).
Собран инструментарием Go 1.20 — последним, который работает на Windows 7.

## Сборка

```
powershell -File build.ps1
```

Результат: `out/POSCloud-Lite-x64.exe` и `out/POSCloud-Lite-x86.exe`
(64-бит и 32-бит). Оба работают на Windows 7 SP1 и новее.

## Настройка

Рядом с программой кладётся файл настроек:

- `client.json` — тот же формат, что у обычного клиента: можно настроить
  папки и режимы на другом ПК и просто скопировать сюда;
- или `poscloud-lite.json` (используется, если `client.json` нет).

Поля: `host`, `port`, `dir`, `token`, `interval`, `folderRules`.
Правка — кнопкой «Настройки…» в окне программы.

## Поведение

- синхронизация идёт в фоне; **закрытие окна её не останавливает** —
  повторный запуск программы возвращает окно;
- журнал — `lite.log` рядом с программой;
- автозапуск при входе в Windows — галочка в «Настройках»;
- режимы папок и правила — как в обычном клиенте (включая «Без правил»
  и «Правило без папки»);
- без интерфейсных функций обычного клиента (снимки экрана, горячие
  клавиши) — они требуют графической оболочки.
