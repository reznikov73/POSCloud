Машина `E:\Work\VSC\POSCloud` (пользователь `rez`), эмулятор BlueStacks Desktop

Грабли эмулятора (новые, важные для следующих проверок):

- **Окно приложения — freeform, и касания смещены вниз примерно на 73 px**
  относительно картинки: чтобы нажать на видимый элемент с координатой `y`,
  нужен `input tap x (y+73)`. Иначе нажатия уходят в содержимое выше (так
  «не работала» нижняя панель вкладок: она нажималась, но на 73 px выше).
  В полноэкранном режиме (`--windowingMode 1` не помог — WM оставил окно)
  смещения не будет.
- **`KEYCODE_BACK` закрывает приложение целиком**, даже когда открыт диалог
  (Fyne отдаёт back системе, `GoNativeActivity` завершается). Проверять
  диалоги только кнопками «Закрыть».
- **`input keyevent KEYCODE_DEL` не доходит до поля ввода Fyne** — очистить
  строку поиска можно только перезапуском приложения.
- `dumpsys window` показывает окно приложения как 648×1065 при видимой области
  ~648×971 — отсюда и смещение касаний.

## 4. Что осталось

1. **Кнопка «Назад»** закрывает приложение (и с открытым диалогом). В чистом Go
   это не перехватить: нужен свой Java-класс активности (категория C плана) или
   согласиться. Пока — записать в известные ограничения для пользователя.
2. **Правая колонка в дереве** (`fileNode`) держится на замерах ширины; в
   результатах поиска размер убран совсем, чтобы не было наложений. Если дерево
   начнёт «съезжать» на другой ширине экрана — делать асинхронное дерево со
   своей раскладкой (остаток пункта 9c ревью).
3. **Проверить на реальном телефоне**: 1.0.42 (лента, конфликты, поиск с
   группировкой, диалог папки). В эмуляторе проверено, на телефоне — нет.
4. Остальное из вечернего хендофа без изменений: экран «Хранилище», «держать на
   телефоне» и автоочистка, PIN, волна 2 (JNI), 16-КБ устройство.

## 7. 1.0.43: компоновка форм переделана (P0–P7)

Сделано всё, что предложено в `docs/ANDROID-FORMS-REVIEW-2026-11-24.md` и показано
в макетах `docs/android-forms-mockups-2026-11-24.html`.

**Сетка и размеры.** `internal/ui/layout.go` — токены `spaceXS/S/M/L = 4/8/12/16`,
`rowMin = 48`, `iconSM/MD = 16/20`, `radiusCard = 12`. Тема: заголовок 20,
подзаголовок 16, текст 14, подпись 12, радиусы 12/12/8, межстрочный 4.
`InnerPadding` оставлен 8: при 12 он раздувал все подписи (12 px текста давали
40 px высоты), и экраны снова становились «воздушными». Высота 48 у кнопок —
через `buttonBox`/`fieldFill` (подложка задаёт минимальную высоту).

**Статус.** Карточка синхронизации — одна строка (заголовок + «работает · цикл
21:42», переключатель по центру), подпись статуса без переноса. Цифры —
сетка 2×2 «подпись слева, значение справа» вместо четырёх плиток 120 dp.
«Передачи: нет» — строка. Карточки без заголовков — своя подложка `cardBox`
вместо `widget.Card` (у Card с пустым заголовком оставалась полоса).

**Связь.** Разделы «Быстрое подключение» и «Сервер». Главное действие —
«Сканировать QR-код» (диалог: сфотографировать / выбрать снимок), вторичные —
«Вставить код из буфера» и свёрнутый ручной ввод. Адрес и порт — одной сеткой
3:1, одинаковой высоты. Токен — одна строка со встроенным «глазом» Fyne
(свой второй глаз убран). TLS — переключатель, отпечаток моноширинный с
подсказкой. «Дополнительно» свёрнут: папка, интервал (с суффиксом «с»), тихие
часы (переключатель + два поля с подписями «с»/«по»), лимит (суффикс «МБ» и
подсказка «0 — без ограничения»), автозапуск. «Проверить связь» и «Сохранить
настройки» закреплены внизу одной строкой; результат проверки и сохранения —
строками, без модалок.

**Ошибки и клавиатура.** Ошибки тихих часов и лимита — красной подписью под
полем, с прокруткой к полю; диалогов для ошибок полей больше нет. Поля —
`formEntry`: цифровая клавиатура для порта, интервала и лимита, прокрутка к
полю при фокусе, «Далее» по цепочке, фокус по касанию (у `Entry.Tapped` пустое
тело, поэтому фокус ставится явно). При смене вкладки клавиатура прячется.

**Папки.** Карточка 150–170 dp заменена строкой: имя, подпись «сервер 57 ·
здесь 23», справа чип режима («В обе», «Отправка», «Приём», «Нет») — по касанию
диалог из четырёх вариантов. Пустые папки — под «Ещё N пустых». «Полная
сверка» и «Обновить» — в меню «⋯» в шапке.

**Файлы и журнал.** Путь — моноширинной подписью, поиск высотой 48. «Конфликтов
нет» — строка; при конфликтах — карточка со счётчиком и кнопкой. Строка дерева
48–56 dp. Журнал: моноширинный 12, общий путь заменён на «…», «Очистить» и
«Сохранить» — иконками в шапке.

**Панель и диалоги.** Панель непрозрачная, подписи 12, высота 56, под ней
полоса 16 под жест-бар; страницы с отступом. Все диалоги — от размера канвы
(`dialogSize`), жёсткие 420 px убраны.

**Проверка.** `go test ./internal/...` — зелёный; новые тесты
`TestFormEntryFocusAndType` (фокус касанием, ввод, цифровая клавиатура),
`TestSwitchRowToggles` (касание по подписи переключает), `TestSaveSettingsInlineErrors`.
APK 1.0.43 установлен в BlueStacks: экраны «Статус», «Связь», «Файлы», «Журнал»
проверены визуально. **Касания в эмуляторе в этой сессии ненадёжны**: буфер окна
повёрнут (1065×648 при окне 648×1065), координаты тапов уезжают — ввод в поля и
цифровую клавиатуру надо проверить на телефоне.

**Не сделано осознанно:** виртуализация списка папок (`widget.NewList` — при
12–30 папках VBox строит их мгновенно), счётчики «отправлено/получено» за цикл
вместо сеанса (нужна правка клиента), экран «Хранилище».

## 8. Состояние на 25.11.2026 и что дальше

**Сделано и лежит в `main`:** коммиты «Движок: конфликтная копия заменяет
прежний суффикс…», «Android: строки списков с обрезкой, лента с операцией,
поиск по папкам», «Документация: хендоф ночи…», «Документация: разбор
компоновки форм…», «Документация: макеты предлагаемой компоновки…» и релиз
1.0.43 (тема, `layout.go`, перекомпоновка всех вкладок).

| Что проверить на телефоне в 1.0.43 | Почему важно |
|---|---|
| Ввод в любое поле «Связи» | поля обёрнуты в `formEntry`; на эмуляторе касания не проверить |
| Цифровая клавиатура у порта, интервала и лимита | `formEntry.Keyboard()` |
| «Далее» по полям формы | цепочка `chain(...)` в `setFormScroll` |
| Прокрутка к полю при фокусе | `formEntry.FocusGained` → `ScrollToOffset` |
| Чипы режимов папок | `folderRow` + `showModeDialog` |
| Закреплённые «Проверить связь» / «Сохранить настройки» | футер вне прокрутки |
| Полоса под нижней панелью | `pagerInset` вместо `bottomInset` над контентом |
| Тихие часы и лимит: ошибки под полями | без модальных окон |

**Если поле на телефоне не получает фокус или не печатает:** откатить обёртку —
в `ui.go` заменить `newFormEntry(...)` и `&formEntry{...}` на `widget.NewEntry()`
и `widget.NewPasswordEntry()`, убрать `setFormScroll` (и вызов), а `chain`
принимать `*widget.Entry`. Потеряются только цифровая клавиатура и автопрокрутка
к полю; всё остальное (вёрстка, ошибки под полями, папки) не зависит.

**Эмулятор BlueStacks в этой сессии:** буфер окна повёрнут (`contentSize=1065x648`
при окне 648x1065), поэтому `input tap` уезжает — касания по координатам
ненадёжны. Визуально проверены «Статус», «Связь», «Файлы», «Журнал»; остальное
нужно смотреть на телефоне или в полноэкранном окне.

**Отложено осознанно:** виртуализация списка папок (`widget.NewList`),
счётчики «отправлено/получено» за цикл вместо сеанса, экран «Хранилище»,
PIN, волна 2 (JNI: Wi-Fi only, уведомления, foreground service).
