Правило проекта (`AGENTS.md`): после изменения кода — тесты, сборка затронутых
приложений, коммит и пуш.

| Изменено | Пересобрать |
|---|---|
| `poscloud-client` | `wails build -s -skipbindings -webview2 browser` + установщик |
| `poscloud-server` | то же + установщик |
| `engine` | клиент + Lite x64/x86 + установщик (движок общий) |
| `lite` | `lite\build.ps1` |
| `installer` | только установщик |
| `poscloud-android` | только APK: `poscloud-android\build.sh` |
| только документация | ничего не собирать |

```powershell
cd E:\Work\VSC\POSCloud\poscloud-android
& 'C:\Program Files\Git\bin\bash.exe' -c './build.sh'   # тесты + APK + проверка 16-КБ
cd ..\lite;      .\build.ps1                            # x64 и x86
cd ..\installer; .\build.ps1 -StopRunning                # поднимает версию, собирает всё + установщик
```

`build.sh` сам подставляет версию из `installer/version.txt` в `AndroidManifest.xml`
(из `AndroidManifest.xml.in`) и в имя файла; APK появляется как
`POSCloud-Client-<версия>-android-arm64-debug.apk`. `versionCode` считается как
`мажор*10000 + минор*100 + патч` (`1.0.35` → `10035`) — обновление всегда старше
установленного.

`installer/build.ps1` поднимает патч в `installer/version.txt` на единицу и всегда
собирает клиент и сервер (кроме `-SkipApps`). Без `-StopRunning` падает, если
POSCloud запущен; **после сборки клиент сам не перезапускается** — поднимите вручную:

```powershell
Invoke-CimMethod -ClassName Win32_Process -MethodName Create -Arguments @{
    CommandLine = '"E:\Program Files\POSCloud\poscloud-client.exe"'
    CurrentDirectory = 'E:\Program Files\POSCloud' }
```

Именно через WMI: обычный `Start-Process` из `exec` умирает вместе с вызовом
(инструмент убивает дерево процессов).

Пуш (Credential Manager в неинтерактивном вызове висит — логин сохранён под
ключом с именем пользователя):

```powershell

git -c credential.username=reznikov73 -c credential.interactive=false push origin v1.0.xx
```

## 5. Грабли (наступали, не повторять)

- **Подпись debug-APK** — встроенный ключ fyne (CN=gomobile), одинаковый для всех
  сборок fyne 1.7.4: ставится поверх. Другой ключ = только удаление приложения.
- **Свой манифест и fyne**: иконку и `uses-sdk` в манифест добавлять нельзя
  («manual declaration … not supported»), атрибуты новее таблицы binres
  (например `requestLegacyExternalStorage`) — «failed to find table ref».
  При своём манифесте fyne **не ставит versionCode** — его подставляет `build.sh`.
- **CRLF**: рабочее дерево в CRLF, инструменты `edit`/`apply_patch` требуют CRLF
  в old/new (либо файл предварительно перевести в LF одной командой).
  `gofmt -w` по всему модулю не запускать.
- **PowerShell 7** не понимает heredoc — текст коммита в файл и `git commit -F`.
- **Fyne 2.8**: нет `widget.Switch` (свой `pillSwitch`), у `widget.Label` нет
  `TextSize` (есть `SizeName`), `Label.Truncation` не обрезает уже разложенный
  текст — режем строку сами по `fyne.MeasureText`.
- **BlueStacks**: `run-as` не работает (`setegid … not permitted`) — приватный
  каталог приложения из shell не прочитать; `screencap` иногда отдаёт чужое окно
  (переснять через 2–3 с); тапы по нижней кромке окна перехватывает менеджер окон.
- **Android и общая память**: создавать/удалять файлы можно, переименовывать —
  нет (см. `moveFile`); открыть файл чужому приложению можно только через
  `content://` из MediaStore, поэтому файлы из приватной папки не открываются.
- **Запуск GUI-приложения из `exec`** — `Start-Process` не живёт после возврата
  вызова; для POSCloud-клиента используйте `Win32_Process.Create` (см. раздел 4).
- **`git push` висит на `credential-manager get`** — в Credential Manager записи
  лежат под ключом с именем пользователя; помогает
  `-c credential.username=reznikov73` (при этом `git config credential.username`
  нигде не задан — это только параметр вызова).

## 6. Открытые вопросы и следующие шаги

1. **Папка синхронизации на телефоне.** Сейчас у пользователя — приватная папка
   приложения (после чистой переустановки): она не видна в проводнике и из неё
   нельзя открывать/устанавливать файлы. Для «как в проводнике» и для установки
   обновления в один тап папку надо держать на общей памяти:
   «Связь» → «Выбрать папку…» → **POSCloud** (`/storage/emulated/0/Download/POScloud`) → «Выбрать эту папку».
2. **FileProvider** — чтобы открывать и устанавливать файлы из любой папки.
   Нужен `<provider>` в манифесте и `res/xml/file_paths.xml`; сборка fyne такое
   пока не собирает (только иконку). Вариант: перейти на aapt2-путь (нужна
   adaptive-иконка `Icon-foreground.png`/`Icon-background.png`).
3. **Обновление**: варианты A (кнопка) и B (автопроверка) сделаны. Осталось по
   желанию: C — endpoint `/android/latest` на сервере (версия, ссылка, sha256)
   вместо поиска файла в папке; D — публикация в RuStore; E (тихая установка)
   недостижима без device-owner.
4. **targetSdk 29 → 34** — отдельная задача: свой манифест, `READ_MEDIA_IMAGES`,
   v2-подпись debug-сборок, поведение edge-to-edge.
5. **Релизный keystore** (ключ на `E:`, вне репозитория): путь подписи в
   `build.sh` готов и проверен тестовым ключом; смена подписи потребует удалить
   debug-версию с телефона.
6. **16-КБ страницы**: линкер исправлен, APK выровнен, но на реальном 16-КБ
   устройстве/эмуляторе `gphone16k` не запускалось.
7. **Галерея телефона**: приложение удаляет только копии в папке синхронизации;
   оригиналы снимков в галерее не трогает (Android 11+ требует диалог
   подтверждения — `MediaStore.createDeleteRequest`).
8. **Мусор в репозитории**: `.finance-tool-capability.json`, `.jw-proxy-…`,
   `.legal-proxy-…`, `.tyc-proxy-…` — не наши, не трогать.
