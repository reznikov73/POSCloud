# Установщик POSCloud

Единый установщик для Windows: на экране выбора компонентов можно отметить
**сервер**, **клиент** или оба сразу.

## Сборка

Нужен [Inno Setup 6](https://jrsoftware.org/isinfo.php) (компилятор `ISCC.exe`).

```powershell
cd installer
.\build.ps1                 # пересобрать оба приложения и установщик
.\build.ps1 -SkipApps       # только установщик (exe уже собраны)
.\build.ps1 -StopRunning    # при необходимости закрыть запущенные POSCloud
```

Готовый файл появляется в `installer\out\` — `POSCloud-Setup-<версия>.exe`.

Версия установщика задана в `poscloud-setup.iss` (`MyAppVersion`), она же попадает
в имя файла и в список «Установка и удаление программ».

## Что делает установщик

- выбор компонентов: **Сервер** и/или **Клиент**;
- ставит приложения в `%LocalAppData%\Programs\POSCloud`
  (при установке «для всех пользователей» — в `Program Files`);
- ярлыки в меню «Пуск», по желанию — на рабочем столе;
- проверяет наличие Microsoft Edge WebView2 Runtime (нужен приложениям;
  в Windows 11 встроен, для Windows 10 покажет ссылку);
- удаление не трогает данные приложения (`users.json`, `server.json`, журналы).
